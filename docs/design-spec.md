# 進路たまごっち（仮）デザイン仕様書

この文書と `docs/design/*.dc.html` が「今のデザイン」の正です。実装で迷ったらここに合わせてください。
数値の計算は `frontend/src/game/rules.js`（サーバー用は `backend/game_rules.py`）、大学と学部のデータは `frontend/src/game/universities.js`（サーバー用は `backend/universities.json`）、キャラの絵は `frontend/src/characters/svg/*.svg` にそのまま入っています。

## 1. 対象と全体の流れ

- 対象：高校生（高1・高2・高3）。中学生・既卒は今は対象外
- 画面の流れ：ログイン → 初期設定1/2（学年・受験日・ペース）→ 初期設定2/2（大学・学部）→ ホーム（起動時の提案）→ 勉強タイマー／手で記録 → （目安を達成した日だけ）ごほうびの着替え
- 1学年＝1シーズン。高1・高2は4月1日〜3月31日、高3は受験日まで。3月31日にキャラは図鑑へ移り、4月1日に新しいたまごがかえる

## 4. 数値ルール（rules.js ／ game_rules.py）

- EXP＝分数×（1＋その教科の配点比率）×連続ボーナス
- 学年の目安：高1 2.5時間・高2 3.5時間（長期休みは1.5倍）、高3は毎日8時間
- 必要EXP＝目標時間×60×平均倍率×学部補正×継続補正1.15×ペース（ゆったり0.8／ふつう1.0／がっつり1.2）
  - 目標時間＝シーズンの10%（最長30日）・45%・85%が過ぎた時点までの、学年の目安の合計
  - 学部補正＝科目数（4で1.00、±5%/科目）×（1＋0.15×記述・実技比率）×大学内補正（東大のみ合格最低点で計算）
- 連続ボーナス：3日×1.05、7日×1.10、14日×1.15、30日×1.20。「続けた日」は学年の目安の1/4以上。週1枚のおやすみ券で連続が切れない。切れたら半分から再開
- 親密度：最終進化のあと、（親密度10のEXP−最終進化のEXP）÷10ごとに＋1。3・5で装備、7でかっこいい姿、10で大のなかよし
- 画面の「あと約◯時間」＝残りEXP÷（60×平均倍率×今の連続ボーナス）、「約◯日」＝それ÷学年の目安
- 例（高3・科学大 工学院・ふつう・2027/4/1〜2028/2/25）：必要EXP 22,500／111,900／211,000、目標時間 240／1,192／2,248時間

## 5. ごほうび

- 上限なし：教科マスター★（教科ごと50時間）、記念メダル（5万EXPごと）、連続記録の称号、季節の着せかえ（月に目安の半分）、おみやげ（親密度10のあと2,000EXPごと・12種）
- レジェンド（金の点線枠）：A判定の王冠／逆転の翼／偏差値70の星章／流れ星／太陽のオーラ
- ミシック（濃い紫に金のふち）：不死鳥の炎／銀河のオーロラ／満開の桜吹雪
- 模試・合格の確認：写真をGeminiで読み取り、判定・偏差値・順位・合否だけ保存して写真は削除。読み取る前に同意をとる

## 6. 着替えのルール

- 場所ごとに1つ（頭・首・胸・手・背中）＋エフェクト1つ。コーデを3つ保存
- 入口はホームに出さない。ホーム右上の灰色の「≡」メニューの中と、目安を達成した日の記録のあとだけ
- 勉強タイマー中はロック（メニューで鍵マーク・薄く表示）。Firestoreのルールでも `timerStartedAt` があるあいだは装備を書き換えられない

## 8. 今のアプリ（学習・進路コックピット）とのつなぎ方

- 今のアプリ：React＋Vite（frontend/）、FastAPI（backend/main.py、Cloud Run「study-advisor-api」）、Firestore（users/{uid}.totalExp、users/{uid}/study_logs）。EXPはサーバーだけが書く
- **今の仕組みは壊さない**：`/advise` の言語化の採点（verbal_score・bonus_exp・advice）と `totalExp` はそのまま残す
- **キャラの成長には新しく「育成EXP」（users/{uid}.growthExp）を使う**
  - 育成EXP＝分数×（1＋志望学部の配点比率）×連続ボーナス×言語化ランク倍率（S 1.3／A 1.2／B 1.1／C 1.0）
  - 言語化ランク倍率を掛けることで、「思考の言語化」が一番大事という今の方針を保ったまま、勉強時間の積み重ねでキャラが育つ
  - 計算は backend/game_rules.py の growth_exp() に倍率を掛けて、main.py の /advise の中で study_logs と同じトランザクションで書く
- 学年の表記：今のアプリの「高校2年生」などは game_rules.py の GRADE_FROM_APP で「高2」に読みかえる
- 新しく users/{uid} に足す項目：targetFacultyId、examDate、pace、plan、growthExp、stage、bond、streak、restTicketWeek、equipped、outfits、timerStartedAt
- 初期設定（学年・受験日・ペース・大学・学部）を保存したら、バックエンドで make_plan() を呼んで plan を保存する（新しいAPI：POST /plan）
- 今の LevelCard の 🥚 を Character コンポーネントに置きかえる（stage は growthExp と plan から決める）
- Firestoreのルールは docs/firestore-rules-snippet.txt を今のルールに足す
