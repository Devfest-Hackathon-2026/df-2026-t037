D-1｜京都大学（ゲタまるに代わる、まったく新しい案）

京大の新しいキャラクター 5案（幼体 → 成体 → 最終進化）

体の形・点の目・ほっぺは9大学共通のまま、大学ごとに変えるのは体の色とアイテム1つ、の決まりで考えた

案A｜時計台前のこたつ

コタまる

京大名物・時計台前に置かれる「こたつ」と、のんびり自由な学風。みかん → 毛布 → こたつ

進化：みかんを頭にのせた豆 → 毛布をしょった成体 → こたつで勉強

  • いちばん「京大らしいネタ」で、話題になる
  • 体の下半分がこたつで隠れる（学部ピンはこたつ布団の上に）
  • 動き：みかんがころん、お茶の湯気

案B｜サル学・フィールドワーク

サルまる

京大が世界をリードしてきたサル学（霊長類研究）と、野外に出て調べる研究スタイル

進化：小さな耳 → 大きな耳としっぽ → 双眼鏡とフィールドノート

  • 動物キャラなので9大学の中で見分けやすい
  • 研究の京大を表せる
  • 顔がピンクのお面になる（顔の決まりの例外）

案C｜校章のクスノキ

クスまる

京大の校章に描かれた大きなクスノキ。葉 → 若木 → 大きな木と黒い実

進化：つやつやの葉1枚 → 小さな木 → 大楠

  • 大学のシンボルそのもので、説明がいらない
  • 東大の銀杏（葉1枚）と植物どうしで少し似る
  • 頭のリボンは木の上に移す必要あり

案D｜大文字の送り火

ダイまる

キャンパスのすぐ東、如意ヶ嶽に灯る「大」の送り火。火の粉 → 山 → 燃える「大」

進化：火の粉 → 小さな山と「大」 → 燃える「大」の山

  • 京都らしさが一目でわかり、火がゆらめいて目立つ
  • 京大ではなく京都の行事なので、大学らしさは弱め
  • 京紫の体で9大学の中で色がかぶらない

案E｜中間子・研究の京大

チュウまる

京大の研究から生まれた「中間子」の理論のように、体のまわりを粒が回る。日本で最初のノーベル賞の研究

進化：光の粒1つ → 輪が1本 → 輪2本と粒3つ

  • 「研究の京大」を一番まっすぐ表せる
  • 動きがきれいで、最終進化の特別感が出る
  • 理系の印象が強く、文系の学部には合いにくい
