### C-6 タイマーが0になったら終わりの音を鳴らす
外部の音声ファイルは使わず、Web Audio で「ポン・ポン・ポーン」と鳴らす。

```js
// frontend/src/lib/chime.js（新規）
let ctx;
/** タイマー開始ボタンを押したときに呼ぶ（スマホは操作の中で一度鳴らす準備が必要） */
export function unlockChime() {
  ctx ??= new (window.AudioContext || window.webkitAudioContext)();
  if (ctx.state === 'suspended') ctx.resume();
}
/** タイマー終了時に呼ぶ */
export function playChime() {
  if (!ctx) return;
  const notes = [[880, 0], [880, 0.35], [1175, 0.7]];
  for (const [freq, t] of notes) {
    const o = ctx.createOscillator(), g = ctx.createGain();
    o.type = 'sine'; o.frequency.value = freq;
    g.gain.setValueAtTime(0.0001, ctx.currentTime + t);
    g.gain.exponentialRampToValueAtTime(0.35, ctx.currentTime + t + 0.02);
    g.gain.exponentialRampToValueAtTime(0.0001, ctx.currentTime + t + (t === 0.7 ? 0.9 : 0.3));
    o.connect(g).connect(ctx.destination);
    o.start(ctx.currentTime + t); o.stop(ctx.currentTime + t + 1);
  }
  navigator.vibrate?.([200, 120, 200]);
}
```
- タイマー画面：開始ボタンの `onClick` で `unlockChime()`、残り0秒になったら `playChime()` → 「もう少し続ける？」（C-16）へ

**C-11 大学内補正（uniFactor）の決め方**（東大の「合格最低点÷平均」と同じ考え方を、ほかの大学では河合塾のボーダーで行う）

```
uniFactor = 1 + 0.02 ×（その学部のボーダー偏差値 − 大学内の平均）
              + 0.005 ×（その学部の共テボーダー得点率 − 大学内の平均）   ← 国公立のみ
→ 0.94〜1.08 の範囲におさめる
```
- 学科が複数ある学部は学科の平均を使う（例：京大 工学部＝6学科の平均 64.6）
- 上の表の uniFactor はこの式で計算済み。新しく学部を足すときも同じ式で出す
- 結果の目安（高3・ふつう・4月開始の最終進化）：京大 医 約1,350時間／京大 農 約1,180時間、科学大 医 約1,290時間／生命理工 約1,150時間

### C-15 ランク（S〜C）をGeminiが「深さ・具体性・次やることの明確さ」で判断する
記録（タイマー終了後・手で記録）のふりかえり文を、Geminiが3つの軸それぞれ0〜2点で採点する。
合計点からランクを決めるのはサーバーのコード（毎回同じ基準になり、「Sにして」と書かれてもずれない）。

| 軸 | 0点 | 1点 | 2点 |
|---|---|---|---|
| 具体性 | 教科だけ（「数学をやった」） | 単元名か量のどちらか（「数列をやった」） | 教材・範囲・量がわかる（「青チャート数列 例題20〜28」） |
| 深さ | 感想だけ（「むずかしかった」「できた」） | どこでつまずいたか・何がわかったか（「漸化式の置き換えがわからなかった」） | なぜつまずいたか（原因）や、わかったこと・自分の考えまで（「+1するのは等比数列の形にそろえるためだと気づいた」） |
| 次やることの明確さ | なし・「がんばる」だけ | 何をするかはある（「漸化式を復習する」） | 何を・いつ・どれだけまでわかる（「明日、例題25と27を解き直す」） |

合計 5〜6点＝S（×1.3）／4点＝A（×1.2）／2〜3点＝B（×1.1）／0〜1点＝C（×1.0）。

```python
【specific 具体性】
0：教科だけ（例：数学をやった）
1：単元名か量のどちらか（例：数列をやった／2時間やった）
2：教材・範囲・量がわかる（例：青チャート数列 例題20〜28）
【depth 深さ】
0：感想だけ（例：むずかしかった、できた）
1：どこでつまずいたか・何がわかったかを書いている（例：漸化式の置き換えがわからなかった）
2：なぜつまずいたか（原因）や、わかったこと・自分の考えまで書いている（例：+1するのは等比数列の形にそろえるためだと気づいた）
【next 次やることの明確さ】
0：書いていない、または「がんばる」だけ
1：何をするかはある（例：漸化式を復習する）
2：何を・いつ・どれだけまでわかる（例：明日、例題25と27を解き直す）

それぞれ、点数の根拠になった部分を文からそのまま抜き出して quote に入れてください（0点なら空文字）。
hint には、いちばん点が低い軸について、この生徒が次に書けばよい一文を、本人の文の内容に合わせて30字以内で書いてください。全部2点なら、ほめる一言を書いてください。

ふりかえり文：
<<<{text}>>>"""

AXIS = {"type": "object",
        "properties": {"score": {"type": "integer", "enum": [0, 1, 2]}, "quote": {"type": "string"}},
        "required": ["score", "quote"]}
SCHEMA = {"type": "object",
          "properties": {"specific": AXIS, "depth": AXIS, "next": AXIS, "hint": {"type": "string"}},
          "required": ["specific", "depth", "next", "hint"]}
AXES = ("specific", "depth", "next")

def rank_of(total: int):
    if total >= 5: return "S", 1.3
    if total == 4: return "A", 1.2
    if total >= 2: return "B", 1.1
    return "C", 1.0

def judge(text: str) -> dict:
    text = (text or "").strip()[:1000]
    if not text:
        return {"rank": "C", "multiplier": 1.0, "scores": {}, "hint": "今日やった範囲を1行書いてみよう"}
    res = client.models.generate_content(
        model=MODEL,
        contents=PROMPT.format(text=text),
        config=types.GenerateContentConfig(
            temperature=0, response_mime_type="application/json", response_schema=SCHEMA),
    )
    r = json.loads(res.text)
    # 根拠の抜き出しが本文にない点数は0にする（書いていないことを評価しない）
    for k in AXES:
        q = r[k]["quote"]
        if r[k]["score"] > 0 and (not q or q not in text):
            r[k]["score"] = 0
    total = sum(r[k]["score"] for k in AXES)
    rank, mult = rank_of(total)
    return {"rank": rank, "multiplier": mult, "total": total,
            "scores": {k: r[k] for k in AXES}, "hint": r["hint"]}
```

### C-16 タイマーが終わったら「もう少し続ける？」を聞き、記録する時間を直せるようにする

- 延長は同じ記録（1回分）にまとめる。延長中も `timerStartedAt` は残す＝着替えロックのまま

- ふりかえり画面の上に「記録する勉強時間」を出す

## 質問への答え（メモ）
- **東京科学大学が「院」なのはなぜ？**：旧東工大の理工系は、学部・学科ではなく「学院」（理学院・工学院など）で学生を募集します。学院は学部と大学院をひとつにした組織の名前で、大学院生だけの入試ではありません。高校生は「工学院」などを選んで受験します（C-13 で画面にも説明を出す）
- **Sランクとは？**：C-5 の説明文のとおり。ふりかえり文の書き方の評価で、Sがいちばん上。S・A・B・Cで、その記録のEXPが ×1.3・×1.2・×1.1・×1.0 になります
